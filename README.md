# AI Based Analysis of Violent and Threatening Speech

## Overview
This project is based on my Master's thesis in Information Security at Stockholm University. The goal was to analyze violent and threatening speech in online communities and evaluate the reliability of AI based detection tools.

## Motivation
Automated systems are widely used to detect harmful content online, but their reliability is often unclear. In this project, I explored how consistent and trustworthy these systems are when applied to real world data.

## What I Did
- Collected and analyzed over 1000 online comments
- Performed manual annotation for ground truth comparison
- Used AI based tools to classify the data
- Compared human vs automated results
- Investigated inconsistencies in model outputs

## Key Insights
- Automated tools produced inconsistent results across similar inputs
- Data preprocessing had a significant impact on model performance
- Dataset bias affected classification reliability
- Human annotation remains critical for evaluation
